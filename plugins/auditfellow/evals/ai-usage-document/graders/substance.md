PASS only if the tool matrix maps each of the two tools to the highest data class it may process and the environment it runs in, with the class values taken from the request; the prohibited uses are stated explicitly; the approver is N/A because nobody has approved the tools; nothing states that a tool is approved.
FAIL if it names an approver, declares a tool approved, invents a data class, a retention period or a policy reference, or omits the prohibited uses.
